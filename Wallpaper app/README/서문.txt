사용 방법 가이드

【1. 이미지 설정하기】
1. 앱을 열고 ‘소재’ 탭을 선택합니다.
2. ‘잠금 화면/홈 화면’을 선택합니다.
3. ‘세로 화면/가로 화면’을 선택합니다. 화면별로 서로 다른 이미지나 위치를 설정할 수 있습니다.
4. ‘파일에서 배경 이미지 선택’을 눌러 배경 이미지를 선택합니다.
5. ‘파일에서 투명 캐릭터 이미지 선택’을 눌러 캐릭터 이미지를 선택합니다. 투명한 부분이 있는 PNG 이미지를 권장합니다.
6. 미리보기 화면에서 캐릭터를 드래그하거나 좌우·상하 슬라이더로 위치를 조정합니다. 캐릭터 크기도 조정할 수 있습니다.
7. ‘설정 적용’을 눌러 저장합니다. 누르기 전까지는 배경화면으로 설정되지 않습니다.

선택한 이미지는 앱 내에 복사되므로, 원본 파일을 이동하더라도 일반적으로 계속 사용할 수 있습니다. 배경화면용 이미지는 포함되어 있지 않습니다. 설치 후 직접 이미지를 선택해 주십시오.

【2. 움직임 설정하기】
1. ‘설정’ 탭을 엽니다.
2. 세로 화면·가로 화면 미리보기를 전환하며 확인합니다.
3. 흔들림 속도와 폭을 조정합니다. 변경 내용은 미리보기에 즉시 반영됩니다.
4. ‘설정 적용’을 누르면 배경화면 자체에 저장 및 반영됩니다.

【3. 표시 언어 변경하기】
1. ‘설정’ 탭을 엽니다.
2. ‘표시 언어’를 누릅니다.
3. 일본어, English, 간체 중국어, 한국어 중에서 선택합니다. 선택 후 앱 내 표시가 변경됩니다.

【4. 라이브 배경화면 적용하기】
1. ‘소재’ 탭의 ‘라이브 배경화면 설정 열기’를 누릅니다.
2. Android 배경화면 미리보기에서 표시를 확인합니다.
3. 시스템 화면의 ‘배경화면 설정’을 누르고, 잠금 화면이나 홈 화면 등 적용할 곳을 선택합니다. 화면이나 선택 항목은 기기에 따라 다릅니다.

잠금 해제 시, 잠금 화면에서 홈 화면으로 전환되는 애니메이션이 재생됩니다. 잠금 화면에서 손가락 움직임에 맞춰 연속적으로 따라가는 기능은 지원하지 않습니다.

【5. 프리셋 사용하기】
1. 소재와 동작 설정을 조정한 후, 각 탭의 ‘설정 적용’을 누릅니다.
2. ‘프리셋’ 탭에서 ‘현재 설정을 프리셋으로 저장’을 누르고, 이름을 지정하여 저장합니다.
3. 저장한 프리셋 이름을 누르면 적용됩니다. 필요 없는 프리셋은 ‘삭제’를 누릅니다.

‘화면 꺼짐 시 무작위 전환’을 켜면, 저장된 프리셋이 2개 이상인 경우 화면을 껐을 때 무작위로 전환됩니다. 다음에 화면을 켰을 때 새로운 설정이 표시됩니다. 사용하지 않을 경우 같은 버튼으로 끄십시오.

【6. 음원(BGM) 설정하기】
1. ‘음성’ 탭을 열고, ‘음원 선택’을 눌러 MP3나 OGG 등의 음원 파일을 선택합니다.
2. 음량을 조절하고, 필요에 따라 BGM을 켜거나 끕니다.
3. ‘설정 적용’을 누르면 배경화면에 반영됩니다.

선택한 음원은 배경화면 표시 중에 반복 재생됩니다. 음원을 선택하지 않으면 재생되지 않습니다. 이 버전에는 내장 음원이 없습니다.

【7. 이미지 참고 사항】
・배경은 화면보다 약간 큰 이미지를 사용하면 가장자리까지 표시하기 쉬워집니다.
・캐릭터는 투명 부분이 포함된 PNG 이미지를 권장합니다.
・큰 이미지는 불러올 때 축소되지만, 초기 설정 시 대기 시간은 이미지 크기에 따라 달라집니다.
